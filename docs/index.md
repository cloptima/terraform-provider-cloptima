# Cloptima Provider

The **Cloptima Terraform Provider** enables platform engineering, FinOps, and security teams to manage AI gateway policies, multi-provider credentials, virtual keys, safety guardrails, MCP tool servers, VPC edge instances, and unit economics denominators declaratively as code.

## Core Capabilities

- **Multi-Provider Routing & BYOK**: Connect OpenAI, Anthropic, Google Vertex AI, Azure OpenAI, and other LLM providers using your own provider credentials.
- **Governance Policies**: Enforce request and token rate limits, daily and monthly spend budgets, per-request token and tool-call ceilings, and model allow/deny lists.
- **Response Caching**: Reduce latency and provider cost with exact-match and semantic caching.
- **Safety & Privacy Guardrails**: Detect prompt injection, jailbreaks, toxicity, PII, and secrets, and observe, redact, or block violations.
- **Model Context Protocol (MCP) Governance**: Authorize and audit tool execution across internal and third-party MCP tool servers.
- **Edge Gateways**: Run the gateway in your own VPC or Kubernetes cluster, governed by the same policies.
- **PromptOps**: Version prompt templates, control version activation, and capture evaluation datasets.
- **FinOps & Unit Economics**: Connect AI inference spend directly to core business metrics (cost per user, cost per order, cost per workflow).

## Example Usage

```terraform
terraform {
  required_providers {
    cloptima = {
      source  = "cloptima/cloptima"
      version = "~> 0.3"
    }
  }
}

provider "cloptima" {
  # Personal access token (PAT) with the ai:admin scope.
  # Recommended: omit this and set the CLOPTIMA_PAT environment variable instead.
  pat_token = var.cloptima_pat
}
```

## End-to-End Starter Blueprint

The following complete configuration provisions a provider credential, creates a production governance policy with caching and guardrails, binds it to an application environment, and issues a virtual key:

```terraform
terraform {
  required_providers {
    cloptima = {
      source  = "cloptima/cloptima"
      version = "~> 0.3"
    }
  }
}

provider "cloptima" {}

# 1. Connect BYOK LLM Provider Credential
resource "cloptima_llm_provider_credential" "openai_prod" {
  display_name  = "OpenAI Production"
  provider_name = "openai"
  api_key       = var.openai_api_key
}

# 2. Establish AI Gateway Governance Policy
resource "cloptima_llm_gateway_policy" "prod_policy" {
  name = "production-gateway-policy"

  # Enforce limits and guardrails (the default, observe, only records decisions)
  mode = "enforce"

  # Exact response cache
  exact_cache_enabled     = true
  exact_cache_mode        = "enforce"
  exact_cache_ttl_seconds = 86400

  # Spend bounds (USD)
  daily_budget_usd   = 500.00
  monthly_budget_usd = 10000.00

  # Rate limits
  request_rate_limit_per_minute = 120
  token_rate_limit_per_minute   = 100000

  # Model access
  allowed_models = [
    "anthropic/claude-sonnet-4-6",
    "openai/gpt-4o",
    "openai/gpt-4o-mini"
  ]

  # Active guardrails
  guardrail_detectors_enabled = [
    "prompt_injection",
    "jailbreak",
    "toxicity",
    "pii",
    "secret"
  ]
  guardrail_output_action              = "block"
  guardrail_cost_mode                  = "enforce"
  guardrail_max_cost_per_request_cents = 10
}

# 3. Bind Policy to Target Environment and App
resource "cloptima_llm_gateway_policy_binding" "copilot_prod_binding" {
  policy_id   = cloptima_llm_gateway_policy.prod_policy.id
  team_id     = "engineering"
  app_id      = "customer-copilot"
  environment = "production"
  priority    = 10
}

# 4. Issue Developer Virtual Key
resource "cloptima_llm_virtual_key" "copilot_key" {
  name                  = "copilot-prod-key"
  team_id               = "engineering"
  app_id                = "customer-copilot"
  environment           = "production"
  default_credential_id = cloptima_llm_provider_credential.openai_prod.id
  expires_in_days       = 180
}

output "copilot_virtual_key_token" {
  value       = cloptima_llm_virtual_key.copilot_key.access_token
  description = "Bearer token for application requests through the AI Gateway"
  sensitive   = true
}
```

## Authentication & Configuration

The provider requires a Cloptima **Personal Access Token (PAT)** with the `ai:admin` scope.

### Credentials via Environment Variables

It is strongly recommended to configure credentials using environment variables:

```bash
export CLOPTIMA_PAT="clop_pat_..."
```

### Static Configuration in HCL

```terraform
provider "cloptima" {
  pat_token = var.cloptima_pat
}
```
